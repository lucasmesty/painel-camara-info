Política de Privacidade

Painel de Controle Câmara · desenvolvido por Lucas Mesty · atualizada em outubro de 2026.

Quais dados o aplicativo acessa

Quando o usuário autoriza a conexão com o YouTube, o aplicativo acessa apenas o necessário para gerenciar as transmissões do canal autorizado: criar, editar e excluir transmissões agendadas e definir título, visibilidade e miniatura.

Como os dados são usados e guardados

As credenciais de acesso ficam armazenadas somente no computador onde o aplicativo está instalado, criptografadas pelo próprio Windows. Nenhum dado é enviado a servidores do desenvolvedor, vendido, compartilhado com terceiros ou usado para publicidade. O aplicativo se comunica apenas com os serviços do Google, para as funções descritas acima, e com equipamentos da rede local.

Como revogar o acesso

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions ou apagando as credenciais nas configurações do aplicativo.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
